# Engagement Close-Out Checklist

> How you end an engagement matters as much as how you start it. A clean handover protects the client, protects your reputation, and sets up the next engagement (with them or through referral). Don't let the last 2 weeks of a project be a messy fade-out.

## Engagement: _______________
## End date: _______________

---

## Knowledge transfer

- [ ] All code, configs, and infrastructure documented (not in your head)
- [ ] Runbooks written for recurring tasks (deployments, monitoring, incident response)
- [ ] Data model documentation up to date
- [ ] ADRs written for all key technical decisions
- [ ] Access credentials rotated / transferred (remove your personal accounts)
- [ ] Open issues / tech debt documented with severity and recommendations
- [ ] Handover sessions scheduled and delivered to the ongoing team

| Governance and access management | | | |

## Client relationship

- [ ] Final status report delivered
- [ ] Lessons learned session run with the client team
- [ ] Sponsor debrief — ask: "What went well? What would you change?"
- [ ] Thank the people who helped (individually, not just in a group email)
- [ ] Ask if they'd be open to being a reference or giving a testimonial
- [ ] Agree on post-engagement support model (if any)

## Business development

- [ ] Follow-up opportunities identified? What's the natural "next phase"?
- [ ] Proposal or scope for follow-on work discussed?
- [ ] Relationships worth maintaining — who should you stay in touch with?

## Personal learning

- [ ] Personal retro completed for the full engagement (not just the last week)
- [ ] Lessons learned log updated with patterns from this engagement
- [ ] Templates in this repo — anything need updating based on what you learned?
- [ ] Portfolio / case study material captured (anonymized if needed)

## Reflection questions

_Spend 20 minutes on these. They're more valuable than any checklist item above._

**What was the single most impactful thing I did on this engagement?**



**What would I do differently if I started this engagement over?**



**What skill gap did this engagement reveal?**



**Did I leave the client better off than I found them?** (Be honest.)



**Would I want to work with this client again? Why or why not?**



---

_Set a calendar reminder for 3 months after close-out to check in with the client. A short "how's the platform going?" message costs nothing and keeps the relationship alive._
