## 3. Training curriculum

| Module | Audience | Duration | Format | Content | Prerequisites | Materials |
|--------|----------|----------|--------|---------|--------------|-----------|
| Platform overview | All | 30 min | Presentation / video | What the platform is, why we built it, how to get access | None | Slides, recording |
| Data model walkthrough | Analysts, stewards | 60 min | Workshop | Core entities, relationships, key fields, naming conventions | Platform overview | Data model docs, ER diagram |
| BI tool hands-on | Analysts, executives | 90 min | Hands-on lab | Build a dashboard, create filters, schedule reports | Platform overview | Lab guide, sample dataset |
| SQL on the new platform | Analysts, engineers | 60 min | Workshop | Dialect differences, performance tips, common patterns | Basic SQL knowledge | Cheat sheet, examples |
| Pipeline development | Engineers | Half day | Pair programming | Build a pipeline end-to-end, testing, deployment | Engineering onboarding | Runbook, code templates |
| Data governance | Stewards, analysts | 60 min | Workshop | Catalog, ownership, quality rules, access requests | Platform overview | Governance checklist |
