# Weekly Focus Check

> A 15-minute exercise for the project lead (or the whole team) at the start of each week. The goal is simple: catch drift early before it becomes a problem. If you can't answer these questions clearly, the project is starting to wander.

_Not a task list. The three things that matter most. If the week ends and only these three things got done, was it a good week?_

## 2. The drift check

_Answer honestly. Circle / bold your answer._

| Question | Answer | Action if "No" |
|----------|--------|----------------|
| Are this week's priorities aligned with the project's top objectives? (check the charter / priority stack) | **Yes** / No | Reprioritize before the week starts |
| Is the team working on what was planned, or have new requests pulled them off track? | On plan / **Drifting** | Identify what pulled you off track; decide if it's a real priority shift or noise |
| Are there any "just a quick thing" requests that have quietly consumed significant time? | No / **Yes** → _what?_ | Route through scope change request |
| Is any work in progress that nobody can explain the business value of? | No / **Yes** → _what?_ | Stop it or justify it |
| Has anything been added to the backlog this week that wasn't there last week? | No / **Yes** → _what?_ | Review against priorities; defer if it doesn't serve top 3 |
