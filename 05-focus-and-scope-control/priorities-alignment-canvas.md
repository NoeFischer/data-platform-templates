# Priorities Alignment Canvas

> Most data platform projects don't fail because people disagree — they fail because people **think** they agree but actually have different priorities. This canvas forces an explicit, ranked conversation about what matters most. Fill it in with the sponsor and key stakeholders, ideally in a room together. Disagreements surfaced here save weeks of wasted work later.

## Instructions

1. Each stakeholder independently fills in their top 3 priorities from the list below (or adds their own)
2. Compare answers — the gaps are where misalignment lives
3. Negotiate until you have **one shared, ranked list**
4. Post it somewhere visible and reference it in every prioritization decision

## How to use this going forward

- **When prioritizing the backlog:** Does this item serve priority #1, #2, or #3? If not, it waits.
- **When a scope change request comes in:** Check it against this stack. If it doesn't serve the top priorities, defer it.
- **When stakeholders disagree on what to build next:** Point to this canvas. The conversation already happened.
- **Revisit quarterly** or when a major project shift occurs.
